## 视觉基准

风格参考 [RhineLabUI](https://github.com/LBEILC/RhineLabUI)（莱茵生命档案终端），沿用其公开的设计规范：

- **浅色**：暖灰白底 `#e8e5e1`、近黑正文 `#080a08`、暖灰辅助 `#77756d`、灰色细线 `#c3bfb6`、暖棕/琥珀强调 `#9b7247`
- **深色**：背景 `#11181b`、正文 `#e0e3dc`、辅助 `#a6b0b1`、分隔线 `#536166`、琥珀强调 `#c5a16b`
- 细线分隔 + 紧凑排字 + 等宽字体标注编号、档案号与章节刻度，不使用圆角卡片和大面积色块

字体使用系统字体栈（MiSans / PingFang SC / 微软雅黑），无外部字体依赖。


## 交互与可访问性

- **接入序列**：首次访问播放约 2.4 秒的档案终端接入动画，可跳过，同一会话内不再重复
- **深色模式**：右上角切换，跟随系统偏好，选择写入 `localStorage`
- **章节刻度**：右侧竖直刻度实时高亮当前章节，顶部导航同步
- **滚动揭示**：`IntersectionObserver` 驱动，同组元素错峰出现
- **键盘**：部门标签支持方向键切换，FAQ 自动收起其他项，Esc 关闭移动端菜单
- **减少动态效果**：`prefers-reduced-motion` 下跳过接入序列、取消动画与揭示效果
- **语义与替代文本**：所有图片带 `alt`，交互元素带 ARIA 状态，触控目标不小于 40px

### 便捷参数

| 参数 | 作用 |
| --- | --- |
| `?noboot=1` | 跳过接入序列 |
| `?s=<章节 id>` | 直接定位到指定章节，如 `?s=pixelsit` |

## 已验证

在 Edge（Chromium，无头）1600×1000 / 1280×560 / 768×1024 / 390×844 四种视口下实测：

- 控制台无报错；13 张图片全部加载成功；四种视口下均无横向溢出
- 部门切换（点击 + 方向键）、FAQ 手风琴、主题切换、章节刻度、移动端菜单开合与 Esc 关闭均正常
- 锚点跳转落点在固定头部下方 102px 处；章节刻度与导航高亮跟随正确，页面触底高亮末尾章节
- 深色模式实际生效：正文 `#11181b`、文字 `#e0e3dc`、收束区块 `#080a08`
